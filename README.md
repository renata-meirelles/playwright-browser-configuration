# Playwright - BaseURL and Browsers Configuration

Projeto de configuração de testes automatizados com Playwright, desenvolvido durante meus estudos de Quality Assurance na Mate Academy.

## Sobre o projeto

Esta atividade tem como objetivo praticar a configuração do Playwright para executar testes automatizados em diferentes navegadores, utilizando uma URL base compartilhada.

## Ferramentas utilizadas

* JavaScript
* Node.js
* Visual Studio Code
* Playwright
* GitHub

## Atividade prática

As configurações trabalhadas neste exercício incluem:

* Configuração de uma BaseURL para a aplicação Conduit.
* Atualização dos métodos de navegação das páginas Sign In e Sign Up.
* Configuração dos navegadores Chromium e Firefox.
* Configuração de testes mobile utilizando Pixel 8.
* Execução dos testes pela linha de comando.
* Configuração do Firefox para executar apenas os testes de Sign In.

## Comandos utilizados

Instalação das dependências:

`npm i`

Instalação dos navegadores:

`npx playwright install`

Execução de todos os testes:

`npx playwright test`

Execução dos testes mobile:

`npx playwright test --project=mobile-chrome`

Execução dos testes no Firefox:

`npx playwright test --project=firefox`
